## # AnesPath — Project Guidelines & Context

## 1. Commands & Dev Server

- Dev server: `npm run dev` (hoặc `npx astro dev --background`)

- Build test: `npm run build`

- Astro Docs: [https://docs.astro.build](https://docs.astro.build)

## 2. Project Identity & Tone

- Name: AnesPath (Learn · Share · Grow)

- Domain: Independent Medical Education (Anesthesiology, Critical Care & Applied Physiology).

- Style: Minimal, academic, clean editorial layout, high-performance static rendering (zero-JS overhead where possible).

## 3. Tech Stack & Styling

- Framework: Astro (Static output).

- CSS: Tailwind CSS v4 via `@tailwindcss/vite` and `src/styles/global.css`.

- Fonts: Switzer (Body), Khand (Headings).

- Deployment: GitHub `PhamMinh26/vibe-portfolio-site`) -> Cloudflare Pages.

## 4. Design Palette (Tailwind Tokens)

- Primary Navy: `#101F35`

- Secondary Navy: `#1B304A`

- Teal Accent: `#8FE3D0`

- Canvas Background: `#F6F8FA`

- Surface: `#FFFFFF`

- Text Main: `#172536`

- Text Muted: `#687789`

- Border Subtle: `#E4EAF0`

## 5. Site Structure (6 Main Sections)

- `/`: Home (Landing page tổng quan, cân bằng hệ sinh thái).

- `/learn`: Thư viện lý thuyết cốt lõi (Applied Physiology + General Anesthesia, Regional Anesthesia, Critical Care).

- `/exam-prep`: Ôn tập thi cử, pearls, ngân hàng câu hỏi.

- `/clinical-tools`: Bộ công cụ tính toán & bảng tra giường bệnh.

- `/clinical-cases`: Phân tích ca bệnh lâm sàng thực tế.

- `/about`: Giới thiệu dự án, tuyên bố miễn trừ trách nhiệm y khoa (disclaimer).
